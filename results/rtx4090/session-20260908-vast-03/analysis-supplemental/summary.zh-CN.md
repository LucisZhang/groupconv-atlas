五项分析均已得到 AUDITED_DESCRIPTIVE。Frontend 使用 frontend-order-corrected.json；首次 frontend.json 保留了计划顺序与实际配置顺序不一致导致的拒绝记录。修正仅允许同一组唯一 shape ID 的顺序变化，支持分母和数值门槛不变。

边界分母为 8 个形状 × 6 个实现 × 3 个驻留/传输边界 × 2 个缓存条件。12 个不支持项来自两种形状的 k2 支持契约。设备图内时间、同步 API 时间和 host-to-host 时间分别解释；eviction_attempt 只表示执行了驱逐缓冲区填充，不能证明所有缓存已清空。五批比较仅给描述比值与 UNCERTAIN。

模型保留全部 12 个原始层及各 6 个实现。28 个不支持项由 12 个几何不支持项和 16 个带 bias 的 native 项组成；另有 8 个带 bias 层的框架基线按计划未测。没有通过去掉 bias 缩小分母。单层卷积结果不表示整模型性能或精度。

Frontend 的分母是 8 个形状 × 2 种布局 × resident/caller_nchw 两条路径，32 项全部 PASS。审计保留候选计划、workspace、数值过滤、选中调优计划、运行时库哈希、流、完整 FP32 和 FP64 点检查。布局分别运行，64 个比较均为描述性 UNCERTAIN；设置、布局转换和搜索费用保持独立。供应商 API 未暴露的逐计划 numerical-note 信息不补写为已验证。

MobileNetV2 使用随机权重，在完整 features[3] block 中仅替换一个固定卷积为 k3，其余操作保留。主计时每项 10 批，按实现随机顺序配对；下表比值均为原始 block 时间 / 替换后时间。

图内获益没有转化为同步 API 获益。API 边界包含输出分配与必需输入物化；图内结果属于另一个计时条件。区间只描述本次运行的批间变化，不代表独立会话确认或整模型加速。

Amdahl 插桩数据单独保留：运行器报告 N=1 的 p=0.20254、目标局部加速 s=1.24375，预测 block 比值 1.04134、插桩实测 1.05873；N=4 分别为 p=0.29825、s=1.70000、预测 1.14000、插桩实测 1.12143。这是四个外部 event 节点及 hooks 括住目标操作的插桩图估计，分析器保存原回执而未单独重新认证这些预测。event 节点会扰动调度，公式还假定其他 block 工作不变；不得与主计时区间混合，也不预测 eager API 或整模型。

另行保存的 eager profiler trace 在主计时后执行，回执明确将目标 GPU 时间占比 p 标为 UNKNOWN：CPU 模块标记不足以分配异步 GPU 工作归属。它不提供另一份可替代的 Amdahl 估计。
